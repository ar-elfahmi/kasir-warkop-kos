## What to build
Setup Laravel Breeze dengan autentikasi username + password (tanpa email). Session-based login. Fitur ganti password. Layout dasar Blade + Tailwind dengan bahasa Indonesia sebagian.

## Acceptance criteria
- [ ] Laravel Breeze terinstall dan terkonfigurasi
- [ ] Tabel users hanya punya field id, username, password, name (tanpa email)
- [ ] Login dengan username dan password berhasil, session aktif
- [ ] Halaman ganti password berfungsi
- [ ] Layout dasar (Blade + Tailwind) sudah dibuat
- [ ] Bahasa Indonesia digunakan di halaman auth
